# 项目顾问与用户自带模型

## 用户如何使用

1. 登录后，在右上角进入「AI 设置」。
2. 选择「服务端默认模型」、`OpenAI 兼容 Chat Completions` 或 `Anthropic Messages`。
3. 若选择用户模型，填入模型名和本次使用的 API Key；OpenAI 兼容接口还可以填写 HTTPS Base URL。
4. 回到某个品牌项目，打开「询问品牌顾问」，选择要关联的商标方案并提问。
5. 若模型确实支持图片输入，可在设置中确认该能力并选择「模型图样复核」。下一次初筛会在本地向量/感知哈希召回后，对前 5 个候选额外显示模型复核意见。

## 安全与数据边界

- API Key 只存在浏览器内存中，并仅随该次请求发送到后端再调用用户选择的模型服务。
- Key 不写入数据库、审计日志、任务记录或页面缓存；刷新页面、退出或关闭标签页后会清除。
- 自定义 OpenAI 兼容地址只接受 HTTPS，以避免将 Key 发往明文接口。
- 项目顾问的问题与答复会保存为项目私有的咨询记录；其他用户和运营后台不能读取。
- 模型视觉复核是辅助意见，不改变本地向量、感知哈希、文字、读音、语义、类别构成的确定性排序，也不改变风险分数。

## 演示时可强调的设计理由

系统把「检索和评分」与「解释和视觉复核」分开：前者稳定、可重复、可展示权重；后者让用户按需要接入自己的模型，生成更易理解的说明。这样既能体现多模态能力，也不会把法律风险判断交给不可控的模型输出。
