# 待确认问题

这些问题会实质影响实现方案，进入对应里程碑前需要确认。

## 课程与交付

1. 最终交付是本地演示、服务器部署、论文/报告，还是三者都需要？
2. 团队人数、周期、现有技术偏好和可用算力是什么？
3. 是否必须使用指定的大模型、LangChain/LangGraph、MySQL 或向量数据库？

## 数据

1. 允许使用哪些商标数据源，授权范围和样本规模是多少？
2. 是否已有商标图片、尼斯分类数据、法规、审查标准和案例材料？
3. 数据是否允许持久化、向第三方模型发送或在课堂展示？
4. 需要支持哪些法域和资料版本？MVP 是否仅限中国大陆商标场景？

## 产品

1. MVP 优先服务普通企业用户、法务，还是知识产权专业人员？
2. Top-K 的默认值、可接受响应时间和报告导出格式是什么？
3. 图像检索是否为首轮演示硬性要求？
4. 用户是否需要账号、历史记录和多人协作？

## 评测

1. 谁可以提供“近似/不近似”和风险等级的人工标签？
2. 是否可以使用教学用合成案例，如何与真实记录清晰区分？
3. 课程评分更看重模型效果、工程完整性、法律可信度还是交互展示？
