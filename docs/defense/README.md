# MarkLens 答辩资料导航

本目录专为答辩准备。它不是产品文档的重复，而是帮助演示者在 30 秒内从一个功能定位到代码、接口、数据模型、测试和演示话术。

| 文档 | 何时使用 |
|---|---|
| [01-feature-map.md](01-feature-map.md) | 老师问“这个功能在哪里实现”时 |
| [02-demo-script.md](02-demo-script.md) | 演示前排练 8-10 分钟完整流程时 |
| [03-architecture-defense.md](03-architecture-defense.md) | 解释权限、RAG、多模态和可信边界时 |
| [../14-comprehensive-optimization-roadmap.md](../14-comprehensive-optimization-roadmap.md) | 展示下一阶段优化方案时 |

源代码入口说明也放在：

- [Web 源码导航](../../apps/web/src/README.md)
- [API 源码导航](../../apps/api/app/README.md)

建议答辩顺序：先走 `02-demo-script.md`，老师追问时打开 `01-feature-map.md`，技术原理追问时打开 `03-architecture-defense.md`。
