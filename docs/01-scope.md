# 项目范围与开发边界

## 1. 产品定位

MarkLens 是商标检索、风险辅助分析和法律文书初稿生成工具。它帮助用户组织证据、发现潜在冲突并形成可复核材料，不替代官方检索、行政或司法判断，也不替代律师意见。

## 2. MVP 用户旅程

### 旅程 A：商标风险初筛

1. 用户输入商标文字、拟使用的商品/服务描述，并选择或确认尼斯分类；
2. 用户可选上传商标图样；
3. 系统执行文字、读音、语义、OCR 文字和视觉多路召回；
4. 系统依据类别相关性、商标状态等元数据重排；
5. 用户查看 Top-K 候选、分项分数、证据与不确定性；
6. 系统给出低/中/高风险提示、修改方向和人工复核提示。

### 旅程 B：生成风险评估报告初稿

1. 用户确认结构化事实和检索候选；
2. 系统检索具有来源定位的法律规则和资料；
3. 系统按固定模板分段生成；
4. 校验器检查事实、引用与必填段落；
5. 用户得到可编辑初稿及校验告警。

## 3. MVP 纳入范围

- 单用户或演示级身份机制；
- 文字检索为必做，图像/OCR 链路可在同一 MVP 后半段接入；
- 小规模、许可清晰、可追溯的离线样本；
- 候选召回、可解释重排、风险提示；
- 商标注册风险评估报告一种模板；
- 引用溯源、缺失事实提示、人工复核提示；
- 基础离线评测与演示数据集。

## 4. 暂不纳入

- 自动抓取或绕过访问限制获取官方/商业数据库；
- 宣称穷尽检索、保证注册成功或给出确定侵权结论；
- 自动生成并提交正式申请、异议、复审或诉讼材料；
- 多租户计费、生产级权限体系和大规模实时监控；
- 在数据不足时由模型虚构案号、法条、主体或事实。

## 5. 质量与合规原则

- **证据优先**：结论必须能回到检索候选、规则或用户事实；
- **分数可解释**：展示分项分数、权重版本和触发规则；
- **未知即未知**：缺失值不默认推定为不利或有利；
- **版本可追溯**：数据、索引、模型、提示词、模板和评分配置均记录版本；
- **人机边界清晰**：结果页面与导出文档持续显示“初筛/初稿、需人工复核”；
- **最小数据原则**：限制上传格式、大小、保留时间和日志内容。

## 6. MVP 验收口径

- 给定固定演示数据，可以稳定返回 Top-K 候选及分项解释；
- 每个结果可追踪到唯一商标记录和数据来源；
- 相同版本配置与输入可复现评分结果；
- 报告中的事实来自用户确认字段或检索证据；
- 法律引用均能定位到知识库记录，不存在的引用会阻断导出；
- 缺少关键事实时系统提出补充项，不自行补造；
- 至少包含一套检索样例、一套生成样例和一组失败场景测试。
