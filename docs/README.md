## 目录约定

- `guides/`：面向使用者、部署者的操作说明；
- `reports/`：实验报告、分工和答辩材料；
- `defense/`：答辩时可直接使用的功能索引与演示稿；
- 根目录历史编号文档：需求、架构、数据、契约和迭代过程的可追溯记录。
