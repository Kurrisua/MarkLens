# 学习中心与外部视频微课

## 用户侧体验

学习中心现在由四层组成：建议学习路径、精选视频微课、可检索知识卡和案例实训入口。

视频使用“精选外链卡片”而不是站内转载或强制嵌入：用户点击后会在新标签页打开原始哔哩哔哩页面。这样保留原作者页面、降低移动端播放器兼容问题，也避免把第三方视频文件保存在 MarkLens 中。

## 运营规则

- 只允许 HTTPS 的 `bilibili.com` 视频链接；后端会校验域名。
- 运营人员需要填写所属学习主题、标题、时长标签和明确的学习目标。
- 草稿视频不会出现在用户端；公开视频与学习专题均发布后才可见。
- 不使用 B 站封面热链，不抓取评论、播放量或用户数据。
- 定期人工复核视频是否失效、是否仍适合教学，失效后可先下架。

## 更新部署

拉取本次代码后执行：

```bash
make db-migrate
make seed
```

`make seed` 是幂等的：它会补充默认的精选视频卡片，不会重复创建已有视频链接。
