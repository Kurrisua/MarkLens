# MarkLens 产品化运行与演示手册

## 启动前配置

复制 `.env.example` 为 `.env` 后，至少修改以下项：

- `AUTH_SECRET`：生产环境使用随机长字符串；
- `DEMO_ADMIN_PASSWORD`：演示运营账户密码；
- `COOKIE_SECURE=true`：HTTPS 部署时必须开启；
- `HEALTH_CHECK_SECRET`：生产环境监控 `/health` 时使用的请求头密钥。

首次运行依次执行：

```bash
make setup
make db-up
make db-migrate
make seed
make dev-api
make dev-web
```

`make seed` 会建立合成商标数据、学习内容、练习题，以及由 `DEMO_ADMIN_EMAIL` / `DEMO_ADMIN_PASSWORD` 指定的演示运营账户。产品化前已有的案例会被归档到该账户的“历史演示归档”项目。

## 用户端演示

1. 打开 `http://localhost:5173`，创建普通账户；
2. 在“我的项目”创建一个品牌项目；
3. 添加商标方案，填写名称、业务描述和尼斯类别，可选上传图样；
4. 查看候选线索，生成风险解读和可编辑报告；
5. 打开“学习中心”和“案例实训”，完成一道判断题。

普通用户无法访问其他账户项目、`/ops` 或数据源同步接口。

## 运营端演示

1. 使用 `.env` 中的演示运营账户登录；
2. 打开 `/ops` 查看项目、任务和学习内容概况；
3. 在“数据源与同步”触发已登记演示数据源的同步；
4. 管理员角色可以查看用户及角色概览；所有角色变更和同步操作会写入审计记录。

运营端只负责平台资产与内容；它不通过用户端资源接口读取全量用户项目。

## 安全核对

- 不使用已退役的 `/api/v1/cases`、`/sources` 等无鉴权旧接口；它们会返回 `410 Gone`；
- API 必须携带 Bearer access token，刷新会话仅通过 `HttpOnly` Cookie 完成；
- 原图、密码、令牌和原始数据源记录不得出现在日志、报告或前端错误提示中；
- 商标结果是演示数据上的初筛，不能宣称已完成官方穷尽检索或得出确定法律结论。
